# Lectionary Data — App Read Logic (Biblia Takatifu)

Files: `lectionary_swahili.json` (source of truth, nested), `lectionary_swahili.sql` (flattened, for SQLite import).

---

## 1. Data Shape

### JSON top-level keys
```
majilio            -> Advent: wiki_01..wiki_03 {dominika_mwaka_A/B/C, siku_za_wiki[]}, desemba_17_hadi_24[]
noeli               -> Christmas: usiku_wa_krismasi_vigilia, usiku_wa_manane, alfajiri, mchana,
                       familia_takatifu{mwaka_A/B/C}, maria_mama_wa_mungu, epifania,
                       ubatizo_wa_bwana{mwaka_A/B/C}, oktava[], baada_ya_epifania[]
kwaresima           -> Lent: jumatano_ya_majivu, baada_ya_majivu[], wiki_01..wiki_05
                       {dominika_mwaka_A/B/C, siku_za_wiki[]}, dominika_ya_matawi{mwaka_A/B/C},
                       wiki_takatifu[], misa_ya_krisma
pasaka              -> Easter: juma_kuu_takatifu{alhamisi_kuu, ijumaa_kuu, vigilia_ya_pasaka},
                       dominika_ya_ufufuo, oktava[], wiki_02..wiki_07{mwaka_A/B/C, siku_za_wiki[]},
                       kupaa_kwa_bwana{mwaka_A/B/C}, pentekoste{vigilia, siku},
                       utatu_mtakatifu / fungu_takatifu_la_mwili_na_damu_ya_kristo /
                       moyo_mtakatifu_wa_yesu {mwaka_A/B/C}
muda_wa_kawaida     -> Ordinary Time (pre-existing wiki_01..wiki_34 structure)
sikukuu_maalum      -> Fixed-date solemnities/feasts (tarehe field, some split INJILI_mwaka_A/B/C)
kalenda_ya_watakatifu -> flat array: {tarehe, jina, daraja, rangi}  (santoral, fixed civil dates)
rangi_za_liturujia  -> color reference dict
mizunguko_ya_miaka  -> {mzunguko_wa_dominika: {year: "A"/"B"/"C"}, mzunguko_wa_wiki: {year: "I"/"II"}}
```

A reading "leaf" object has: `SOMO_LA_KWANZA`, `WIMBO_WA_KATIKATI`, `SOMO_LA_PILI` (nullable),
`SHANGILIO`, `INJILI` (or `INJILI_mwaka_A/B/C` when only the Gospel varies by year).

### SQL tables (generated by flattening the JSON)
```sql
readings(id, season, period_key, entry_key, day, somo_la_kwanza, wimbo_la_katikati,
         somo_la_pili, shangilio, injili, mwaka_liturujia)
watakatifu(id, tarehe, jina, daraja, rangi)
rangi_za_liturujia(rangi PRIMARY KEY, maelezo)
mizunguko_ya_miaka(mwaka PRIMARY KEY, mzunguko_wa_dominika, mzunguko_wa_wiki)
```
Use `readings` for day-to-day lookups in the app (index on `season, period_key`); keep the JSON
bundled as a fallback / for anything not flattened (e.g. the 7 OT readings inside
`vigilia_ya_pasaka.masomo_ya_agano_la_kale`, which only exist in JSON).

## 2. Core Algorithm: "What are today's readings?"

Given a `LocalDate today`, resolve in this order:

```
1. Compute movable anchor dates for the civil year (see §3: Computus).
2. Determine which liturgical SEASON `today` falls in (see §4: season boundaries).
3. Within that season, resolve the specific PERIOD_KEY / ENTRY_KEY (see §5).
4. Resolve the Sunday cycle (A/B/C) or Weekday cycle (I/II) needed, from
   mizunguko_ya_miaka, keyed by the correct "liturgical year" (see §6).
5. Check kalenda_ya_watakatifu and sikukuu_maalum for a fixed-date override
   that outranks the seasonal weekday (see §7: precedence).
6. Query `readings` (or walk the JSON) with the resolved keys.
```

### Kotlin sketch
```kotlin
data class ResolvedDay(
    val season: String,
    val periodKey: String,
    val entryKey: String?,   // e.g. "dominika_mwaka_A", "mwaka_B.vigilia", weekday index
    val cycleYear: String?   // "A"/"B"/"C" or "I"/"II", null if not needed
)

fun resolveLiturgicalDay(today: LocalDate): ResolvedDay {
    val anchors = computeAnchors(today.year)          // §3
    val season = detectSeason(today, anchors)          // §4
    val (periodKey, entryKey) = detectPeriod(today, season, anchors) // §5
    val cycleYear = resolveCycle(today, season)         // §6
    return ResolvedDay(season, periodKey, entryKey, cycleYear)
}
```

## 3. Computus: Movable Feast Anchors (per civil year)

Only **Easter Sunday** must be computed (Anonymous Gregorian / Meeus algorithm); every other
movable date is an offset from it.

```kotlin
fun easterSunday(year: Int): LocalDate {
    val a = year % 19
    val b = year / 100
    val c = year % 100
    val d = b / 4
    val e = b % 4
    val f = (b + 8) / 25
    val g = (b - f + 1) / 3
    val h = (19 * a + b - d - g + 15) % 30
    val i = c / 4
    val k = c % 4
    val l = (32 + 2 * e + 2 * i - h - k) % 7
    val m = (a + 11 * h + 22 * l) / 451
    val month = (h + l - 7 * m + 114) / 31
    val day = ((h + l - 7 * m + 114) % 31) + 1
    return LocalDate.of(year, month, day)
}

data class Anchors(
    val ashWednesday: LocalDate,      // Easter - 46 days
    val palmSunday: LocalDate,        // Easter - 7 days
    val holyThursday: LocalDate,      // Easter - 3 days
    val goodFriday: LocalDate,        // Easter - 2 days
    val easterVigil: LocalDate,       // Easter - 1 day (Holy Saturday night)
    val easterSunday: LocalDate,
    val ascension: LocalDate,         // Easter + 39 days (Thu) — many US provinces
                                       //   TRANSFER to Easter + 42 (the following Sunday);
                                       //   app should expose a per-diocese setting, default = Sunday
    val pentecost: LocalDate,         // Easter + 49 days
    val trinitySunday: LocalDate,     // Easter + 56 days
    val corpusChristi: LocalDate,     // Easter + 60 days (Thu) — same transfer note as Ascension,
                                       //   default = following Sunday (Easter + 63)
    val sacredHeart: LocalDate,       // Friday after 2nd Sunday after Pentecost = Easter + 68
    val firstSundayAdvent: LocalDate, // Sunday nearest Nov 30 (between Nov 27–Dec 3)
    val christTheKing: LocalDate      // Sunday before firstSundayAdvent
)

fun computeAnchors(year: Int): Anchors {
    val easter = easterSunday(year)
    val advent1 = firstAdventSunday(year)  // see helper below
    return Anchors(
        ashWednesday   = easter.minusDays(46),
        palmSunday     = easter.minusDays(7),
        holyThursday   = easter.minusDays(3),
        goodFriday     = easter.minusDays(2),
        easterVigil    = easter.minusDays(1),
        easterSunday   = easter,
        ascension      = easter.plusDays(42),   // default: transferred Sunday
        pentecost      = easter.plusDays(49),
        trinitySunday  = easter.plusDays(56),
        corpusChristi  = easter.plusDays(63),   // default: transferred Sunday
        sacredHeart    = easter.plusDays(68),
        firstSundayAdvent = advent1,
        christTheKing  = advent1.minusDays(7)
    )
}

fun firstAdventSunday(year: Int): LocalDate {
    // Sunday closest to Nov 30, i.e. the Sunday in [Nov 27, Dec 3]
    var d = LocalDate.of(year, 11, 27)
    while (d.dayOfWeek != DayOfWeek.SUNDAY) d = d.plusDays(1)
    return d
}
```

> **Note on Ascension/Corpus Christi:** the US Ordo transfers these to Sunday in most provinces
> (Boston, Hartford, New York, Omaha, Philadelphia keep Thursday). Ship a boolean setting
> `keepThursdaySolemnities` (default false) and branch accordingly — do not hard-code one option.

## 4. Season Boundaries

```
Majilio (Advent)      : [firstSundayAdvent(year), Dec 24]
Noeli (Christmas)     : [Dec 25 (year-1 if today < Jan 6), Baptism of the Lord]
                         Baptism of the Lord = Sunday after Epiphany
                         Epiphany = Sunday in [Jan 2, Jan 8] (US); Jan 6 elsewhere — make configurable
Kwaresima (Lent)       : [ashWednesday, holyThursday morning / before Evening Mass]
Triduum (in "pasaka")  : [holyThursday evening, easterVigil night]
Pasaka (Easter)        : [easterSunday, pentecost]
Muda wa Kawaida        : everything else, in TWO separate blocks:
                         Block 1: [dayAfterBaptismOfLord, dayBeforeAshWednesday]
                         Block 2: [dayAfterPentecost, dayBeforeFirstSundayAdvent]
```

```kotlin
fun detectSeason(d: LocalDate, a: Anchors): String = when {
    !d.isBefore(a.firstSundayAdvent) && !d.isAfter(LocalDate.of(a.firstSundayAdvent.year, 12, 24))
        -> "majilio"
    isInChristmasWindow(d, a)   -> "noeli"
    isInLentWindow(d, a)        -> "kwaresima"
    isInTriduumOrEasterWindow(d, a) -> "pasaka"
    else -> "muda_wa_kawaida"
}
```

## 5. Resolving `period_key` / `entry_key` Inside a Season

- **Advent**: `weeksBetween(firstSundayAdvent, today) + 1` → `wiki_0N`; if `today` is
  Dec 17–24, use `desemba_17_hadi_24` array indexed by date instead (it outranks the weekly
  cycle per the rubrics).
- **Christmas**: match exact date to the fixed keys (`usiku_wa_manane`, `alfajiri`, `mchana`,
  `oktava[]` by date, `baada_ya_epifania[]` by weekday-offset). `familia_takatifu` = the Sunday
  falling within the Christmas octave (or Dec 30 if Christmas itself is a Sunday — see §7).
- **Lent**: `weeksBetween(firstSundayOfLent, today) + 1` → `wiki_0N`; `wiki_takatifu[]` for the
  Monday–Wednesday of Holy Week; `dominika_ya_matawi` for Palm Sunday.
- **Easter**: `oktava[]` for the 6 weekdays right after Easter Sunday; then
  `weeksBetween(easterSunday, today) + 1` → `wiki_0N`; `kupaa_kwa_bwana` /
  `pentekoste` / `utatu_mtakatifu` / etc. resolved directly from the Anchors dates.
- **Ordinary Time**: week number = `ceil(daysBetween(seasonStart, today) / 7)`, continuing the
  running count across both blocks (do NOT reset the counter after Easter — consult the
  official Ordo table per year, since the jump varies).
- **Weekday `siku` index**: `today.dayOfWeek.value` mapped Mon=0..Sat=5 (Sundays never index into
  `siku_za_wiki`, they use the `dominika_mwaka_X` sibling key instead).

## 6. Resolving the Reading Cycle

```kotlin
fun liturgicalYearFor(d: LocalDate, a: Anchors): Int =
    if (!d.isBefore(a.firstSundayAdvent)) d.year + 1 else d.year

fun resolveCycle(d: LocalDate, season: String): String? {
    val ly = liturgicalYearFor(d, computeAnchors(d.year))
    return when {
        needsSundayCycle(season) -> mizunguko["mzunguko_wa_dominika"][ly.toString()]  // "A"/"B"/"C"
        needsWeekdayCycle(season) -> mizunguko["mzunguko_wa_wiki"][d.year.toString()] // "I"/"II"
        else -> null
    }
}
```
`mizunguko_ya_miaka` in the JSON/SQL only covers 2024–2035 — extend the table (formula: cycles
repeat A→B→C→A every liturgical year; weekday cycle is simply odd-year=I, even-year=II) or
compute it on the fly with `((liturgicalYear - 2026) mod 3)` mapped against the known 2026=A
anchor.

**Note (today, Aug 15 2026):** liturgical year 2026 = Sunday Cycle **A**, calendar year 2026 =
Weekday Cycle **II** — already correct in the shipped table; verified against the USCCB 2026
Ordo.

## 7. Precedence Rules (what overrides what)

Highest to lowest, per *Universal Norms on the Liturgical Year*, Table of Liturgical Days:

1. Triduum, Christmas, Epiphany, Ascension, Pentecost (proper-of-time solemnities)
2. Solemnities in `sikukuu_maalum` and Sundays of Advent/Lent/Easter
3. Solemnities in `kalenda_ya_watakatifu` with `daraja = "Sikukuu Kuu"` (none currently, all
   general-calendar solemnities are already routed through `sikukuu_maalum`)
4. Feasts of the Lord in Ordinary Time; Sundays of Ordinary Time
5. **Weekdays of Advent Dec 17–24 and all weekdays of Lent** — these beat Feasts/Memorials
   from `kalenda_ya_watakatifu` (per the Norms). App logic: if season is Kwaresima, or Majilio
   AND date ∈ [Dec 17, Dec 24], skip `kalenda_ya_watakatifu` entirely.
6. `daraja = "Sikukuu"` entries in `kalenda_ya_watakatifu`
7. `daraja = "Kumbukumbu"` (obligatory memorial)
8. Ordinary weekdays (`muda_wa_kawaida` weekday cycle I/II)
9. `daraja = "Kumbukumbu ya Hiari"` (optional — only offered as an alternative, never forces a
   change of readings; app should surface it as "leo pia ni ukumbusho wa..." without swapping
   the Mass readings)

```kotlin
fun resolveWithPrecedence(today: LocalDate): ResolvedDay {
    val seasonal = resolveLiturgicalDay(today)
    if (seasonal.season in setOf("majilio", "kwaresima") &&
        isDec17to24OrAnyLentWeekday(today)) return seasonal   // rule 5, short-circuit
    val fixed = kalendaYaWatakatifu.find { it.tarehe == today.toSwahiliMonthDay() }
    return if (fixed != null && fixed.daraja != "Kumbukumbu ya Hiari") fixed.asResolvedDay()
           else seasonal
}
```

**Special date-shift rules to implement explicitly** (not derivable from the tables alone):
- If Dec 25 falls on a Sunday, `familia_takatifu` moves to **Dec 30** (Friday), not the next
  Sunday, because Jan 1 must remain the Octave/Mary Mother of God.
- If Epiphany lands on Jan 7 or 8, Baptism of the Lord moves to the **following Monday**
  instead of waiting for Sunday.
- `dominika_ya_matawi` and Holy Week are always fixed by `easterSunday`, never by week-counting.

## 8. Query Examples (SQLite)

```sql
-- Advent, 2nd Sunday, Year B
SELECT * FROM readings
WHERE season='majilio' AND period_key='wiki_02' AND entry_key='dominika_mwaka_B';

-- Today is a Lent weekday, week 3, Tuesday
SELECT * FROM readings
WHERE season='kwaresima' AND period_key='wiki_03'
  AND entry_key='siku_za_wiki' AND day='Tue';

-- Transfiguration (year-split gospel), Year C
SELECT somo_la_kwanza, wimbo_la_katikati, somo_la_pili, shangilio, injili
FROM readings
WHERE season='sikukuu_maalum' AND period_key='kubadilika_sura_kwa_bwana'
  AND mwaka_liturujia='mwaka_C';

-- Saint of the day
SELECT jina, daraja, rangi FROM watakatifu WHERE tarehe = 'Juni 3';

-- Which Sunday cycle is 2026?
SELECT mzunguko_wa_dominika, mzunguko_wa_wiki FROM mizunguko_ya_miaka WHERE mwaka = 2026;
```

## 9. Known Gaps to Flag in the App

- `muda_wa_kawaida.wiki_01`–`wiki_34` predates this data drop and has **no `SHANGILIO`** yet —
  UI should hide the acclamation row gracefully (null-check) rather than show a blank field.
- Easter Vigil's 7 Old-Testament readings live only in JSON
  (`pasaka.juma_kuu_takatifu.vigilia_ya_pasaka.masomo_ya_agano_la_kale`, an array) — not
  flattened into `readings`; the Vigil screen must read the JSON directly or you must extend
  the SQL generator.
- `kalenda_ya_watakatifu` is a curated ~85-entry subset of the General Roman Calendar
  (Solemnities/Feasts/obligatory Memorials + common optional ones) — not the full missal; treat
  a lookup miss as "no proper saint today, use the weekday/Ordinary-Time readings" rather than
  an error.
- Ascension/Corpus Christi Thursday-vs-Sunday depends on (arch)diocese — must be a user/region
  setting, not hard-coded.
